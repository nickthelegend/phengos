# Phengos (φέγγος, "glow")

Twelve small paper lights hide around your real room: behind the couch, under the table, in a ceiling
corner. Find them by pointing, by looking, by saying "catch", or with one switch. If you can't see well,
follow their hum. Every way to play is a first-class way.

A Meta VR Start 2026 entry (Gaming track, New Experience division), built with the Immersive Web SDK.
